# Belastingaangifte Checker — Domain Glossary

## Terms

**Belastingaangifte**
The Dutch income tax return filed with the Belastingdienst. Single document per tax year. Source of truth for comparison. Amounts are rounded to full euros (no cents).

**Jaaropgave**
An annual statement issued by a financial institution (bank, broker, mortgage provider) summarising a taxpayer's financial position or transactions in a given year. Multiple jaaropgaves may be uploaded per session.

**Instelling**
The financial institution that issued a jaaropgave. Detected automatically from PDF content. Classified as one of: `bank`, `broker`, `hypotheek`, `other`.

**Rekeningnummer**
Account number (IBAN or broker account ID) used as the primary key for matching a jaaropgave entry to an aangifte entry.

**Gedekt**
A matched item where the aangifte and jaaropgave share the same rekeningnummer and their amounts match (after rounding both to full euros).

**Jaaropgave ontbreekt**
An item present in the aangifte for which no corresponding jaaropgave was uploaded.

**Niet ingevuld in aangifte**
An item present in an uploaded jaaropgave but absent or zero in the aangifte — a potential oversight by the taxpayer.

**Aandachtspunt**
A substantive flag generated by the analyst. Based on a seeded rule set (see `rules/aandachtspunten.md`) plus open-ended LLM judgment. Each aandachtspunt names the triggering condition and its tax implication.

**Box 1 / Box 2 / Box 3**
The three income boxes in the Dutch tax system. Box 1: work and home ownership. Box 2: substantial interest in a company. Box 3: savings and investments. The aangifte is structured around these boxes.

**Extractie**
The first LLM pass: reading a PDF (sent as a native document block) and returning structured data — institution type, rekeningnummers, and relevant amounts.

**Analyse**
The second LLM pass: receiving all extracted data and producing the four-category comparison report plus aandachtspunten. Matching is primarily by rekeningnummer; amount comparison rounds both sides to full euros.
